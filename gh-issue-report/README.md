# gh-issue-report

Розширення для GitHub CLI: показує відкриті задачі, згруповані за першою міткою.
Задачі без міток виводяться в окремій групі «без мітки».

```bash
cd gh-issue-report && gh extension install .
gh issue-report                 # поточний репозиторій
gh issue-report owner/repo      # інший репозиторій
```
